# d1-3B

[LiquidAI/d1-3B](https://huggingface.co/LiquidAI/d1-3B) answers yes/no, choice,
and scoring questions about text and images. It can answer several questions
about the same input in a shared pass.

Requires macOS 27 and Apple M4 or newer. The model download is about 6.3 GB.
Install the [Tinkerbox app or Python package](../../README.md#quickstart);
model files download automatically on first use.

## Usage

In the app, choose **d1-3B** on the Decision screen. In Python:

```python
import tinkerbox_ane

with tinkerbox_ane.load("d1-3b") as model:
    result = model.system_one("Hi! I was charged twice.", {
        "greeting": {"type": "noul", "instructions": "Is this a greeting?"},
        "refund": {"type": "noul", "instructions": "Is this a refund request?"},
    })
    print(result["answers"])
```

Use `choice` questions to select an option and `score` questions to rate an input
across ordered levels. `system_one_batch` handles several inputs. Results include
answers, input-token usage, Neural Engine time and estimated compute.

## Images and limits

Pass Pillow images with `images=[Image.open("photo.jpg")]`; text may be `None`
when an image supplies the input. Several questions about the same pictures
share image processing.

The context limit is **32,768 tokens**, including questions and image tokens.
Use `model.count_tokens(text, questions, images=images)` to preview usage.

`model.max_image_tiles` controls retained image detail: 1–10 tiles per picture,
with a default of 6. Lower values reduce image processing time and token usage.
The app exposes this under **Model Settings**.
